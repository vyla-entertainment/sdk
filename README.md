# Vyla SDK

VylaSDK is a JavaScript/TypeScript SDK for accessing Vyla's stream providers, subtitles, and download sources directly from Node.js. Instead of using the Vyla REST API, developers can run the scraping layer directly in their own environment with full control over requests, execution, and provider management.

### Installing

To start, install VylaSDK through npm or pnpm:

```bash
# npm
npm install @vyla-entertainment/sdk

# pnpm
pnpm install @vyla-entertainment/sdk
```

Please note we do not provide proxying, you have to do that on your end.

**View our full documentation at:** https://docs.vyla.cc/sdk
